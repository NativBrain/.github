# NativBrain/.github

Default issue and pull request templates for every NativBrain repo. GitHub applies them to any repo in the org that has no templates of its own.

This repo is public because GitHub requires it for org-wide defaults. Keep it to templates only: nothing about our products or code goes here.

| File | Used for |
|------|----------|
| `ISSUE_TEMPLATE/task.md` | New issues. English title, Spanish body. |
| `PULL_REQUEST_TEMPLATE.md` | New pull requests. Spanish body. |

A repo that needs something different (for example, NativVision's forward-port section) keeps its own template, which wins over these. For issues it is all or nothing: a repo with its own `.github/ISSUE_TEMPLATE/` folder ignores every issue template here.
